Downstream data science experiments, anomaly detection benchmarks, and fraud audit pipelines require exact, bitwise identical reproduction when initialized with the same configuration and seed.

## 3. Deterministic Architecture & Design Principles

The generator achieves bitwise determinism through the following architectural design choices:

1. **Isolated Pseudo-Random Number Generators (PRNG)**:
   - Generation logic uses a locally instantiated `np.random.default_rng(seed)`.
   - No reliance on global random state (`random.seed()` or `numpy.random.seed()`). Multiple generation pipelines running concurrently in the same process do not cross-contaminate.
2. **Centralized Deterministic ID Counters (`IDFactory`)**:
   - Sequential, format-validated identifiers (`PR-2026-000001`, `PO-2026-000001`, `QUO-SUP-A-0001-2026-000001`) are allocated by a single centralized factory instance passed by reference.
3. **Fixed Calendar 2026 Anchor**:
   - Zero reliance on wall-clock system time (`datetime.now()`). Requisition dates adhere strictly to fixed calendar year 2026 bounds parameterized by configurable monthly weights.
4. **Stable Primary-Key Row Sorting**:
   - Prior to serialization to CSV or JSON, all record collections are stably sorted by primary key, guaranteeing deterministic line-by-line ordering.
5. **Topological Foreign-Key Insertion Order**:
   - DDL schema execution and database inserts follow a strict topological dependency order, preventing foreign key race conditions and ensuring deterministic SQLite table contents.
