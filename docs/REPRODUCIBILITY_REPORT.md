## 3. Deterministic Architecture & Design Principles

The generator achieves bitwise determinism through the following architectural design choices:

1. **Single Random Generator Pass-Through**: Exactly one `numpy.random.Generator` instance is initialized at entry (`seed=20261022`) and passed down to each subsystem.
2. **Zero Global Random State**: The Python `random` module and unseeded NumPy methods are strictly excluded from all generation routines.
3. **Fixed Reference Epoch**: All timestamps originate from base date `2026-01-01`; no calls to `datetime.now()` or system clocks exist.
4. **Monotonic Primary Key Sequences**: `IDFactory` maintains independent deterministic integer counters for each entity prefix.
5. **Stable Serialization**: CSV writers maintain sorted column manifests; JSON dumps specify explicit indentation and sorted dictionary keys.
6. **Double-Entry Balance Convergence**: Financial arithmetic utilizes Python `decimal.Decimal` with explicit rounding to prevent floating-point platform divergence.
