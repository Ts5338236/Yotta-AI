## 3. Deterministic Architecture & Design Principles

The generator achieves bitwise determinism through the following architectural design choices:

1. **Isolated Pseudo-Random Number Generators (PRNG)**:
   - Generation logic uses a locally instantiated `np.random.default_rng(seed)`.
   - No reliance on global random state (`random.seed()` or `numpy.random.seed()`). Multiple generation pipelines running concurrently in the same process do not cross-contaminate.
2. **Centralized Deterministic ID Counters (`IDFactory`)**:
   - Sequential monotonic sequence counters generate predictable, ordered identifiers (`PR-2026-000001`, `PO-2026-000001`, etc.).
   - Counters are reset and synchronized between lifecycle stages.
3. **Deterministic FX & Integer Arithmetic**:
   - Exchange rates are fixed Decimals defined in configuration.
   - All internal arithmetic operates on integer minor units (cents) or fixed Decimal scales, eliminating cross-platform IEEE 754 floating-point rounding divergence.
4. **Stable Topological Row Ordering**:
   - Tables are exported with deterministic primary key sorting before serialization to disk, preventing arbitrary dictionary-hash iteration order from altering file contents.
5. **Standardized Serialization**:
   - Dates and timestamps follow exact ISO 8601 UTC formatting (`YYYY-MM-DDTHH:MM:SSZ`).
   - Line breaks are unified (`\n`), and CSV text escaping follows RFC 4180 rules.
